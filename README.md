# 🎵 PPlay v0.1.0 [LAB][START]

Simple audio player written in **Python** using **Pygame** and **Tkinter**.

PPlay allows you to play your own music tracks through a lightweight and simple graphical interface.

---

## 🚀 Installation

### 1. Install Python

Download and install Python.

Recommended version:

```
Python 3.13.12
```

---

### 2. Install dependencies

Open a terminal in the project folder and run:

```bash
pip install pygame
```

---

### 3. Add sound files

Create a folder named:

```
sound
```

inside the project directory.

Put the file:

```
sound.py
```

inside the `sound` folder.

Example:

```
PPlay/
│
├── main.py
├── README.md
│
└── sound/
    ├── sound.py
    ├── track1.mp3
    ├── track2.mp3
    └── track3.mp3
```

Add your own music tracks into the `sound` folder.
