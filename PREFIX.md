###PREFIXES
#[START]
the version with which the project was launched
#[LOST]
The version files are lost, i.e. the binaries and source codes
#[ATTENTION]
dangerous version, use the code at your own risk, I do not answer
#[LAB]
the version or branch is a laboratory version and cannot have a stable version
#[TESTING]
testing is being conducted, in the future it will have a prefix corresponding to my opinion about the version
#[LTS]
a stable version that has been tested over time
#[LTS PLUS]
A stable version that will definitely work for a long time.
#[LTS GOLD]
The version is outdated but not far from #[LTS] or #[LTS PLUS]
