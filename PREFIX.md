# PREFIXES

## Main prefixes

### [START]
The version with which the project was launched.

### [LOST]
The version files are lost, i.e. the binaries and source codes.

### [ATTENTION]
Dangerous version. Use the code at your own risk. I am not responsible for possible issues.

### [LAB]
The version or branch is a laboratory version and cannot be considered stable.

### [TESTING]
Testing is being conducted. In the future, it will receive a prefix corresponding to my opinion about the version.

### [LTS]
A stable version that has been tested over time.

### [LTS PLUS]
A stable version that is expected to work reliably for a long time.

### [LTS GOLD]
An outdated version, but still close to #[LTS] or #[LTS PLUS] status.


# TESTING STAGES

## Secondary prefixes

### [BLUE]
Code testing is being carried out.

### [RED]
The first part of monthly testing.

### [YELLOW]
Mid-month testing stage.

### [GREEN]
Testing is almost finished.

### [VIOLET]
A critical error has been found and is being fixed. After that, testing starts again from [RED].
